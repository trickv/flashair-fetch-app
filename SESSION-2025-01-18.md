#### 2. Network Security Fix (Commit: 6a3b24a)
**Issue:** "Cleartext HTTP traffic to 10.0.2.2 not permitted"

**Solution:** Created `android/app/src/main/res/xml/network_security_config.xml`
- Allows HTTP for emulator localhost (10.0.2.2)
- Allows HTTP for FlashAir IP ranges (192.168.x.x)
- Referenced in AndroidManifest.xml

**Critical:** Android 9+ blocks HTTP by default. This config is essential for development and FlashAir connectivity.

#### 3. Git Commit ID Display (Commits: b97c038, 8eaa8be, 1c7f055)

**Attempt 1 (Failed):** BuildConfig with `buildConfigField()`
- **Error:** JDK jlink failures with Android Studio's bundled JDK
- **Root Cause:** BuildConfig generation triggered JdkImageTransform, incompatible with snap-installed Android Studio

**Attempt 2 (Success):** resValue() for string resource
```kotlin
// build.gradle.kts
val gitCommitId = providers.exec {
    commandLine("git", "rev-parse", "--short", "HEAD")
}.standardOutput.asText.get().trim()
resValue("string", "git_commit_id", gitCommitId)

// MainActivity.kt
val gitCommitId = context.getString(R.string.git_commit_id)
Text("Build: $gitCommitId")
```

**Result:** App footer now displays actual git commit hash, updates automatically on rebuild.

#### 5. Build Environment Investigation

**Attempted:** Running Gradle tests locally in Claude Code environment

**Findings:**
- Gradle can reach proxy server (21.0.0.73:15004)
- Proxy returns 401 Unauthorized for Gradle's authentication attempts
- JWT token in proxy credentials not accepted by Gradle's HTTP client
- curl works fine (handles proxy auth differently)

**Conclusion:** Unit tests work perfectly (pass in CI), but cannot run locally due to environment proxy authentication. Continue using GitHub Actions CI for Android builds/tests.

### Critical Discoveries

1. **Network Security Config is Essential**
   - Without it, all HTTP connections fail on Android 9+
   - Must explicitly whitelist development and FlashAir IPs

2. **BuildConfig Issues with Modern Android Studio**
   - `buildConfigField()` triggers JDK image generation
   - Causes jlink failures with snap-installed Android Studio
   - `resValue()` is safer alternative for build-time values

3. **Emulator Networking**
   - `10.0.2.2` reliably routes to host machine's localhost
   - Mock server works perfectly from emulator

4. **FAT Date Encoding Matters**
   - Previous test bug: Used wrong FAT date (March instead of September)
   - Correct calculation critical for file timestamp accuracy
